## 🎨 Customization

To personalize this portfolio for yourself:

1. **Profile info** — Update name, bio, avatar image URLs in `index.html`
2. **Social links** — Replace `href` values for GitHub, Facebook, TikTok, Email
3. **Projects** — Edit the `.project-card` sections with your own projects
4. **Skills** — Adjust `data-width` values on `.skill-fill` elements
5. **Stats** — Change `data-count` values on `.stat-value` elements
6. **GitHub Stats** — Replace `username=vincentsensei` with your GitHub username
7. **Music** — Replace the audio `src` URL in the `<audio>` tag
8. **Colors** — Edit CSS variables in `:root` inside `style.css`
